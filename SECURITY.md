# Security and privacy

This application runs in the browser and does not require an external server. Do not add telemetry or automatic uploads of `.data` files.

Radio codeplugs may contain DMR IDs, contact lists, position settings, and other private information. Do not attach real files to public GitHub Issues.

For security issues, contact the repository maintainer privately if a contact method is listed on their GitHub profile. Otherwise open an Issue containing no sensitive exploit details or user data, requesting a private contact channel.
