# Repository structure

```text
index.html            Complete app, GitHub Pages entrypoint; double-click for offline use
README.md             Beginner-friendly instructions and publication steps
LICENSE               MIT license
CONTRIBUTING.md       Contributions and validation expectations
SECURITY.md           Privacy and responsible reports
.gitignore            Excludes personal codeplug files
.nojekyll             Lets GitHub Pages serve files as-is
.github/              Issue and pull-request templates
src/                  Development HTML and modular JavaScript sources
tests/                Unit tests (Node.js)
docs/                 Format and deletion reverse-engineering notes
```

**Do not upload original radio `.data` files to a public repository.**
